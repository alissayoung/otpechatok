# Отпечаток

Дневник, который сохраняет не то, как выглядел день, а то, как он ощущался.
Человек пишет о дне, прикладывает фото и песню, а система собирает из этого живую страницу дневника. Фото становятся объёмной картиной, написанной в стиле, который выбрало настроение дня, а песня в реальном времени управляет светом, ритмом и частицами.

Кейс «Make the Invisible Visible», Genesis Hackathon ArtTech 2026.

## Как это работает

```
Текст ─► Claude (или словарь) ─┐
Фото  ─► палитра, свет, глубина ┼─► Вектор атмосферы (6 осей) ─► веса 6 художественных режимов
Песня ─► BPM, лад, энергия ────┘                                  │
                                                                   ├─► шейдерная сцена 9:16
                                                                   ├─► «Почему так?»
                                                                   ├─► голос озвучки
                                                                   └─► папка дня (ZIP) и архив
```

**Вектор атмосферы:** тон (valence), энергия, теплота, близость, ностальгия, насыщенность. Каждая ось складывается из текста, фото и музыки по формулам из [`lib/vector.ts`](lib/vector.ts), и каждое сработавшее правило попадает в панель «Почему так?».

**Постоянные элементы:** формат 9:16, бумажное поле, окно фото 4:5 со скруглёнными краями, дата моноширинным шрифтом вверху слева, название дня антиквой (Cormorant Garamond), рукописная подпись (Caveat), «Партитура дня» внизу (волна песни + кривая настроения текста + бегунок).

**Переменные элементы:** художественный режим и его смешение, палитра из фото, светлая или тёмная бумага, размер окна (больше при людях и насыщенном дне, меньше в тихий день), частицы из текста, ритм смены кадров по такту песни, зерно по ностальгии.

## Художественные режимы

| Режим | Референс | Когда | Техника |
|---|---|---|---|
| Импрессия | Клод Моне | спокойно, тепло, хорошо | фильтр Кувахары + мазки по полю шума, мягкое свечение |
| Композиция | Василий Кандинский | высокая энергия, напряжение | жёсткий контраст, круги и линии на бит выходят за окно |
| Вырезки | Анри Матисс | энергия + радость | постеризация в палитру дня, рваный бумажный край |
| Ноктюрн | Джеймс Уистлер | грусть, низкая энергия, вечер | туман по карте глубины, приглушённый тон |
| Плёнка | любительская фотография 70–90-х | ностальгия, старая песня, друзья | хроматическое смещение, ореол, засветка, зерно |
| Ма | японская гравюра укиё-э | один, тихо, мало событий | контур Собеля, плоские заливки, пустота |

Режимы не выбираются «один из», а смешиваются по весам, поэтому два спокойных дня тоже выглядят по-разному.

## Запуск

```bash
npm install
npm run dev
```

Переменные окружения (все необязательные, без них приложение работает):

| Переменная | Зачем | Без неё |
|---|---|---|
| `ANTHROPIC_API_KEY` | анализ текста и название папки через Claude (`claude-opus-5-5`) | словарный анализ русского текста |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | общий архив в Supabase | дни хранятся в IndexedDB браузера |

Для Supabase один раз выполните [`supabase/schema.sql`](supabase/schema.sql) в SQL Editor. Это демо-режим без авторизации: все, у кого есть адрес сайта, видят архив.

## Инструменты

- Next.js, React, TypeScript, Three.js (свои GLSL-шейдеры)
- Claude API (`@anthropic-ai/sdk`): анализ текста со структурированным JSON-ответом
- Deezer API: поиск песни и официальное 30-секундное превью; oEmbed Spotify/YouTube для разбора ссылок
- Свой аудиоанализ на Web Audio: БПФ, спектральный поток, автокорреляция темпа, профили Крумхансла для лада
- Depth Anything V2 Small через transformers.js (загружается в браузере с CDN), иначе псевдо-глубина
- Open-Meteo: погода дня по геолокации, с согласия
- Web Speech API для озвучки, MediaRecorder для видео, JSZip для папки дня
- Supabase или IndexedDB (idb-keyval) для хранения
- Шрифты Google Fonts: Cormorant Garamond, Caveat, JetBrains Mono

Песни целиком не хранятся: в папке дня лежат ссылка и результаты анализа. Оценка настроения — художественная интерпретация, а не психологическая диагностика.
